# Tabby

Barra a schede per macOS (su Hammerspoon): ogni app o finestra è una scheda.

- `tabby.lua` — il programma
- `CLAUDE.md` — istruzioni per Claude Code (leggile per prime)
- `docs/PRODOTTO.md` — mission, cosa fa oggi, cosa migliorare
- `docs/ROADMAP-v1.md` — cosa faremo nella v1
- `test/` — Mac simulato e test (`test/run_all.sh`)

**Per iniziare con Claude Code:** apri Claude Code in questa cartella e scrivi:
"Leggi CLAUDE.md e i documenti in docs, poi mettiamo in funzione Tabby da questa cartella."
